# PROJECT FUSION FACTORY

A repeatable pipeline for prototyping original Roblox games by recombining high-level mechanics.
Internal codename for the first prototype: **PROJECT FLOW** (provisional, not name-cleared).

- `PROJECT_FUSION_FACTORY_MASTER_PLAN.md` — master operating plan (legal, compliance, pipeline)
- `MISSION_001_PLAN.md` — Mission 001A technical plan
- `STATUS.md` — what has really been done and verified
- `CLAUDE.md` — binding operating constraints for Claude Code
- `docs/` — technical documentation
- `legal/` — IP, provenance and name-clearance templates
- `games/project_flow/` — the first prototype (`src/shared`, `src/server`, `tests`)

Nothing here is published. No Robux or money is spent by this repository.
