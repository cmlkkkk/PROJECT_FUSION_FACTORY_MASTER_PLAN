# IP Rules (template)

Summary of master plan section 2. The master plan prevails on any conflict.

## Clean-room design
- Study games only through normal authorized play and public material.
- For each reference, write an abstract MECHANICS NOTE: observation -> abstract principle -> original implementation.
- Do not decompile, extract assets, use leaked source, circumvent DRM, or copy maps, animations, sounds,
  UI layouts, dialogue, lore, characters or distinctive item designs.

## Checklist before any asset or system is accepted
- [ ] Original expression, not a copy of an identifiable source
- [ ] Provenance recorded in `ASSET_PROVENANCE.md`
- [ ] Human creative direction documented for key IP
- [ ] AI-assisted output reviewed for accidental similarity
